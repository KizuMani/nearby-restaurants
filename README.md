# 近くのごはん

いまいる場所（または駅名・地名）の近くの飲食店を、**「今の自分」に合う順**に並べて紹介するスマホ向けのウェブアプリです。APIキーは不要で、サーバーも使いません。

- 公開ページ：<https://kizumani.github.io/nearby-restaurants/>
- 想定している使い方：社内テスト・個人利用（下の「制約・注意」を参照）

## できること

- **お店をさがす：** 現在地、または駅名・地名から、半径300m〜2kmの飲食店を検索します。ジャンルの絞り込み、「営業中のみ」、「今日はここ！」（上位からランダムに1軒）もあります。
- **今の気分で並べ替え：** 「早く済ませたい」「今日は誕生日」「がっつり食べたい」などを入力する（または例をタップする）と、並びがその場で変わります。言葉の辞書で読み取るため、AIは使っていません。
- **プロフィールで並べ替え：** ユーザーネーム、生年月日、好きなジャンル（3つまで）、普段使えるごはん代を登録すると、好みと予算に合うお店が上に来ます。20歳未満は居酒屋・バーを表示せず、誕生日当日は「特別な日」向けに並べます。
- **各お店の表示：** 支店名、営業中かどうか、価格の目安（推定）、おすすめの理由、距離。上位3件には「こんなときに」の一言が付きます（営業時間と場面の提案だけで、味や評判の断定はしません）。
- **同名のお店の見分け：** 二重に登録されたお店は1件にまとめます。支店名がないチェーン店は、最寄り駅からの距離を添えます。

## 仕組み

サーバーのない静的サイト（HTML / CSS / JavaScript）で、GitHub Pages で公開しています。

| 用途 | 使っているもの |
|---|---|
| お店のデータ | OpenStreetMap の Overpass API（無料の公開サーバーを複数並べ、遅いときは同時に別のサーバーへ問い合わせ） |
| 地名の検索 | OpenStreetMap の Nominatim |
| 地図 | Leaflet と OpenStreetMap のタイル |
| 営業中の判定 | opening_hours.js（suncalc、i18next を併用） |
| 書体 | M PLUS Rounded 1c（Google Fonts） |

- **端末に保存するもの：** プロフィールと、検索した場所の周辺のお店のデータ（最大6か所、混み合うときの代用）。どちらもこの端末のブラウザの中だけで、外部には送りません。
- **外部に送られるもの：** お店の検索のための座標（Overpass）、入力した地名（Nominatim）、地図の表示範囲（OpenStreetMap）。
- **セキュリティ：** 画面の説明（CSP）で、通信先と読み込み元を限定しています。お店の名前などは、画面に出す前に無害化しています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | お店をさがす画面 |
| `profile.html` | プロフィール設定画面 |
| `app.js` | 検索、データ取得、二重登録の統合、支店名、表示 |
| `shared.js` | プロフィールの保存、気分の読み取り、点数づけ、一言の文言 |
| `scene.js` | 上部の街のイラスト（その場で描画） |
| `profile.js` | プロフィール設定画面の動作 |
| `style.css` | 見た目 |

## 手元で動かす

このフォルダで次を実行し、<http://127.0.0.1:8765/> を開きます。

```bash
python -m http.server 8765
```

位置情報の取得は、`localhost` か HTTPS のページでだけ動きます。

## 更新・公開の手順

`main` ブランチの直下が、そのまま公開されます。

1. GitHub のこのリポジトリで「Add file」→「Upload files」を選び、ファイルをドラッグして「Commit changes」を押します。
2. 1〜2分で反映されます。スマホでは、Safari のタブを閉じて開き直します。

**更新するときの決まり**

- `index.html` と `profile.html` の中の `?v=` の版番号（例：`style.css?v=20261016a`）を、**必ず新しい値に変えます。** GitHub Pages は、ファイルを10分間記憶するため、HTML だけ新しく CSS / JS が古い状態になり、画面が崩れることがあります。
- 端末に保存するお店のデータの形式を変えたときは、`app.js` の `CACHE_PREFIX` の版（現在 `v2`）も上げます。

## 制約・注意

- **評価・口コミはありません。** お店のデータ（OpenStreetMap）に含まれていないためです。「おすすめ順」は、営業中か、距離、登録情報の充実度、プロフィールと気分で決めています。
- **価格は推定です。** ジャンルや店名からの目安で、実際の価格とは異なります。
- **営業時間や店情報は、古い・未登録のことがあります。** ジャンルの判定も、店名からの推定のため、誤ることがあります。
- **無料の公開サーバーを使っているため、混み合うことがあります。** 自動で再試行や別サーバーへの切り替えをします。
- **事業としての利用には向きません。** GitHub Pages も、OpenStreetMap の公開サーバーも、商用サービスを前提としていません。多くの人に配る場合は、有料のデータ提供元などへの切り替えが必要です。
